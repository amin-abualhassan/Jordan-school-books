# Jordanian school textbooks (Grades 1–12)

PDFs of the official Jordanian school textbooks (NCCD, 2025/2026), organized by
grade → subject → semester, ready to upload to Google Drive.

**Download:** [Releases → textbooks-2025-2026](../../releases/tag/textbooks-2025-2026)
— one zip per grade plus `INDEX.csv`. Extract all zips into the same place; they
merge into one folder, `Jordan-School-Books-2025-2026`. Drag that folder into
Google Drive and share it as "Anyone with the link → Viewer". Total ≈ 13 GB.

- `REPORT.md` — what was collected, where each file came from, and what is missing.
- `PLAN.md` — how it was done.
- `catalog/` — the book list taken from NCCD's pages, mirror mappings, corrections.
- `scripts/`, `.github/workflows/` — the pipeline that builds the release.

The books are © National Center for Curriculum Development (المركز الوطني لتطوير
المناهج), published free at https://www.nccd.gov.jo (reachable from inside Jordan).
